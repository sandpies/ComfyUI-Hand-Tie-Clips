Give the writer a brain.

The writer is a text AI that runs on your own PC. Pick your graphics card, follow the steps for one tool, and the writer pill on the node turns green. You only do this once.

1 · Which graphics card do you have?

Pick one above and the best tool for it gets a ★ pick badge.

Download it from lmstudio.ai and open it.

1

Install basalt: paste this into PowerShell

Start menu → type PowerShell → open it → paste → Enter. It downloads the latest basalt, checks the file is intact, unpacks it to C:\basalt and sets up its Python. It tells you if anything is missing.

& { $Dir = 'C:\basalt' [Net.ServicePointManager]::SecurityProtocol = 'Tls12' $ErrorActionPreference = 'Stop'; $ProgressPreference = 'SilentlyContinue' Write-Host '[1/5] Finding the latest basalt release...' # the newest release that already has its Windows zip (a fresh release can be empty for a while) $a = (Invoke-RestMethod 'https://api.github.com/repos/jesdga95/basalt/releases?per_page=10') | ForEach-Object { $_.assets } | Where-Object { $_.name -like '*windows-x64.zip' } | Select-Object -First 1 if (-not $a) { throw 'No Windows build found on the basalt releases page. Try again later.' } $zip = Join-Path $env:TEMP $a.name Write-Host "[2/5] Downloading $($a.name)..." Invoke-WebRequest $a.browser_download_url -OutFile $zip if ((Get-FileHash $zip -Algorithm SHA256).Hash.ToLower() -ne $a.digest.Split(':')[1]) { throw 'Checksum mismatch: the download is damaged. Run this again.' } Write-Host "[3/5] Unpacking to $Dir..." $tmp = Join-Path $env:TEMP 'basalt_unpack'; Remove-Item $tmp -Recurse -Force -ErrorAction SilentlyContinue Expand-Archive $zip $tmp -Force $src = (Get-ChildItem $tmp -Recurse -Filter basalt.exe | Select-Object -First 1).Directory.Parent.FullName New-Item -ItemType Directory $Dir, "$Dir\models" -Force | Out-Null Copy-Item "$src\*" $Dir -Recurse -Force Remove-Item $tmp, $zip -Recurse -Force Write-Host '[4/5] Setting up its Python (one minute)...' if (-not (Get-Command py -ErrorAction SilentlyContinue)) { throw 'Python is missing: install it from python.org (3.10 or newer), then run this again.' } py -3 -m venv "$Dir\.venv" & "$Dir\.venv\Scripts\python.exe" -m pip install -q --disable-pip-version-check -r "$Dir\requirements.txt" Write-Host '[5/5] Checking your GPU setup...' where.exe cudart64_13.dll *> $null if ($LASTEXITCODE -ne 0) { Write-Host 'Missing: the CUDA 13 runtime. Install the CUDA Toolkit 13 from developer.nvidia.com/cuda-downloads, then restart.' -ForegroundColor Yellow } Write-Host "Done. Put your .basalt model file in $Dir\models" -ForegroundColor Green }
2

Add a model

basalt runs .basalt model files. Put yours in C:\basalt\models. The node uses the newest one there, or the file you set in ⚙.

3

Press Start

Press ⚙, pick basalt, then Start. The first load takes about half a minute. With ☕ Auto-Wake on, just write: the node starts it for you.

basaltbasalt ReadyStart
Before every render the node unloads basalt's model to free the card and reloads it on your next write. Keep Unload on Run ticked in ⚙.

Install nInfer: paste this into PowerShell

It downloads the latest Windows build (about 450 MB), checks it, unpacks it to C:\ninfer, then opens nInfer's own model picker: type a number and press Enter.

& { $Dir = 'C:\ninfer' [Net.ServicePointManager]::SecurityProtocol = 'Tls12' $ErrorActionPreference = 'Stop'; $ProgressPreference = 'SilentlyContinue' Write-Host '[1/4] Finding the latest nInfer Windows release...' $a = (Invoke-RestMethod 'https://api.github.com/repos/natpate/ninfer-windows/releases?per_page=10') | ForEach-Object { $_.assets } | Where-Object { $_.name -like '*.zip' } | Select-Object -First 1 if (-not $a) { throw 'No Windows build found on the nInfer releases page. Try again later.' } $zip = Join-Path $env:TEMP $a.name Write-Host "[2/4] Downloading $($a.name) (about 450 MB)..." Invoke-WebRequest $a.browser_download_url -OutFile $zip if ((Get-FileHash $zip -Algorithm SHA256).Hash.ToLower() -ne $a.digest.Split(':')[1]) { throw 'Checksum mismatch: the download is damaged. Run this again.' } Write-Host "[3/4] Unpacking to $Dir..." $tmp = Join-Path $env:TEMP 'ninfer_unpack'; Remove-Item $tmp -Recurse -Force -ErrorAction SilentlyContinue Expand-Archive $zip $tmp -Force $src = (Get-ChildItem $tmp -Recurse -Filter ninfer-serve.exe | Select-Object -First 1).Directory.FullName New-Item -ItemType Directory $Dir, "$Dir\models" -Force | Out-Null Copy-Item "$src\*" $Dir -Recurse -Force Remove-Item $tmp, $zip -Recurse -Force Write-Host '[4/4] Pick a model to download (nInfer runs its own .ninfer files only)...' Push-Location $Dir; try { cmd /c download_model.bat } finally { Pop-Location } Write-Host "Done. nInfer is in $Dir" -ForegroundColor Green }
2

Press Start

Press ⚙, pick nInfer, then Start. With ☕ Auto-Wake on, just write: the node starts it for you.

nInfernInfer ReadyStart
nInfer cannot unload in place, so before a render the node stops it, and Auto-Wake starts it again when you next write (about 30 s). Keep Unload on Run ticked.

If it doesn't turn green

Pill says Offline after StartThe red bar under it says why. The full log is C:\basalt\bin\server.err or C:\ninfer\server.err.
"No model selected"Local server only: type the model's name in the model box in ⚙, or load one in LM Studio.
The render runs out of VRAMTick Unload on Run in ⚙. With llama.cpp, close the server first.
"Python is missing" (basalt)Install Python 3.10 or newer from python.org and paste the installer again.
"Missing: the CUDA 13 runtime" (basalt)Install the CUDA Toolkit 13, restart, then press Start.
Empty or cut-off plansUse a bigger context (16384 or more) or a stronger model. With Ollama, see its note above.
"Checksum mismatch"The download broke on the way. Paste the installer again.
