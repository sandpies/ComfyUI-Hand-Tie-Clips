Every feature, in one place

29 features. NEW marks what arrived after 4.0.

Node

H3 Ref2VA Chain

Strings MiniMax H3 generations (“hops”) into one long clip. Each hop picks up where the last one ended, picture and sound together.

Find it: Load the Starter workflow, or Add Node → Hand Tie Clips → H3 Ref2VA Chain.

Run tab → pin_mech

Join modes

How hop N+1 grabs hop N. auto (the default) hands over the last frames as a latent (Motion-Context). sand_tie renders a take as one long piece. hand_tie steers hops from a quick low-res previs: experimental, and the least consistent of the three.

Find it: Leave it on auto unless you are testing.

Media tab → master_audio_file

Song lock

Give the chain your song. Every hop is timed against it, so the music runs straight through a music video instead of restarting at each join.

Find it: Media tab: pick the song, drag the bar to where the video starts.

Run tab → cache_hops

Hop cache & retakes

Finished hops are kept. Change one beat and re-queue: only that hop (and what follows it) renders again.

Find it: Run tab: cache_hops = on. Timeline: pick a hop, render hop.

Control Room → Studio

MV Studio NEW

From a song to a plan: a treatment (the idea, the hook, the worlds), location plates and cast sheets to generate, all in one place. New: the treatment leads, and you choose the sheet backdrop.

Find it: Studio tab. The Sheets: dropdown picks black, gray or white backdrops.

Control Room → Refs

References

Name your cast, places, props and voices once; beats call them as @name. Each row sets how large the text model sees that picture.

Find it: Refs tab. Drop pictures in, give each a short @name.

Control Room → RefMod

RefMod & sheet stitcher NEW

Turn several stills of one character or look into a single reference. The stitcher packs stills into one sheet in the browser; Lossless keeps every pixel 1:1.

Find it: RefMod tab → Shots → Sheet.

Control Room → Media

Any frame rate in NEW

Reference clips at 25, 30 or 60 fps are re-timed to H3's 24 fps on the way in, so motion and lip sync line up.

Find it: Nothing to set: it happens when a clip is loaded.

Control Room → Swap

Swap NEW

Put your character into an existing video. The clip is read by the vision model and rewritten as a plan with your cast in it.

Find it: Swap tab: load the video, pick who goes in.

Control Room → Script

Script NEW

The shot plan: one row per hop, what the camera sees and hears. New: a JSON drawer to paste or copy the whole plan.

Find it: Script tab; the JSON drawer is at the bottom.

Control Room → Write

Write (local AI writer)

Describe the idea; a writer running on your own PC drafts the shot plan, asks what it needs, and edits on request. Any OpenAI-compatible local server works (LM Studio, llama-server, Ollama, KoboldCpp, vLLM), or nInfer.

Find it: Write tab → writer settings: pick Local server and its address, or nInfer.

Control Room → Standard

Standard

The single-clip writer inside the chain node: one prompt, written to H3's official six-field format.

Find it: Standard tab.

Node

SandTie PromptRig NEW

A prompt rig for one H3 generation: dials for camera, light, look and action, a Reference Bible, and a writer — your local LLM, or Instant CPU Tie with no GPU at all. Outputs a prompt for the stock H3 node, or the conditioning itself. New: SOUND dial, Ultra-Realism looks, Extract Beats from a video.

Find it: Add Node → Hand Tie Clips → SandTie PromptRig (H3). Also as its own pack.

Agent skill

Director co-pilot

A directing partner for your coding agent (Claude Code, Codex, OpenCode or any harness that reads skills): song or story → treatment → shot plan → checked, ready-to-queue graph, then retakes.

Find it: prompt_pack/skills/director-copilot — copy it into your agent's skills folder.

Node

Steering Dials

Push motion, expression, energy and mood up or down without rewriting the prompt. Make Steering Dial builds your own from prompt pairs.

Find it: Add Node → Hand Tie Clips → HTC Steering Dials (H3).

Node

H3 Token LoRA

One LoRA, separate strengths for the video, the soundtrack, the reference pictures and the prompt — so a look LoRA can stay off the voices.

Find it: In the Starter's model chain.

Node

AdaLN LoRA Fix

Makes LoRAs trained on the full model work on pruned checkpoints. Token LoRA already does it for you.

Find it: Only needed with other LoRA loaders.

Node

SLA+ sparse attention

Attention that skips what does not matter. Faster hops; reference protection keeps faces and places held.

Find it: In the Starter's model chain.

Node

H3 Cache

Skips sampling steps whose features have barely moved. Built on silveroxides' cache.

Find it: Add Node → Hand Tie Clips → H3 Cache, between the model and the chain.

Automatic

Prompt encode cache NEW

Encoded prompts and references are kept on disk, so re-running a plan skips the text model for everything that did not change.

Find it: Nothing to set.

All nodes

V3 nodes NEW

Every node now uses ComfyUI's newer node format. Same widgets, same saved workflows; ready for the newer frontend features.

Find it: Nothing to set. Old workflows load as before.

Run tab → upsample

Upsample in the chain

Finish the chain at about 2 MP: H3's latent upscaler, then a short re-draw that adds real detail. Fine-tune it with the Upsample Settings node.

Find it: Run tab: upsample = on.

Node

Video Upsampler

Upscale any finished clip. The file-to-file version works a piece at a time, so a long video never fills your RAM.

Find it: Load the Upsample_Video_File workflow.

Node

Save Video & Load Video (path)

Save long clips with the GPU encoder and optional RTX frame generation (24 → 48 fps). Load Video (path) skips ComfyUI's 100 MB upload limit.

Find it: In the upsample workflows.

Node

Chain Preview

Watch hops arrive while the chain renders.

Find it: Sits on the IMAGE wire before CreateVideo in the Starter.

Control Room → Timeline

Timeline

Every hop on a strip. Scrub them, play one with sound, and inspect any join exactly as the final video has it.

Find it: Timeline tab, or the dock under the graph.

Timeline → ▦ wall

Render wall NEW

Every finished hop looping at once. Click one to open it.

Find it: Timeline header: ▦ wall.

Timeline → wall

Pop-out monitor (browser & phone) NEW

Open the wall in its own browser tab, or a phone-sized window with a link for your phone. Follows the render live: hop strip, finish time, finished hops looping.

Find it: Wall header: ⧉ browser / 📱 phone. On a real phone, start ComfyUI with --listen.

Hop previews build two at a time and in the background as each hop finishes, so the wall opens without pinning your CPU.
