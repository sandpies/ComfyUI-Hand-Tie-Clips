# Director

Coverage overlay. Load after the mode guides when the request is cinematic, Hollywood, movie-cut, directive, Flux-style editing, or “direct this.” Stacks with combat-scene.md. Look / Astro Cinema rules live only in `astro-cinema.md` — stack that overlay only when the user asked for both this turn. Official shot timestamps and camera verbs still come only from `base-en.md`, or from `multishot.md` when that chain is on. Inner motion-clock ranges come from `field-craft.md` and are not extra cuts. Chain `---` boundaries are airlock joins, not director cuts. Do not treat a named animation studio as a director trigger.

Shots that are not already named are a Plan turn (`planning.md`). Do not invent the board inside the prompt. The storyboard picks jobs from `references/coverage-menu.md`. After confirm, write those jobs. The size menu in §2 is the default mix when no row applies.

I2VA / FL2VA still default to one shot unless the user asked for cinematic cuts, or `performance.md` is on and the face-beat count requires a split.

The H3 node has no memory of prior clips. Never mention earlier takes, file names, or “same as last pass” in any field.

## 1. Shot budget

When this overlay is on, change camera **size or axis** about every 2–3 seconds unless the user asked for a long take. Five-second hangs on one size go stale. Sixteen micro-cuts with `HOLD` / `static` become a slideshow.

A cut must start on motion already happening (pickup mid-swing, mid-sprint, mid-roll). Distance-only or slight-angle changes stay camera motion: track, truck, push, pull, arc, pedestal, whip-pan. A size change on one gesture uses the Match on action row in `references/coverage-menu.md`.

One deliberate exception: comedic or reaction-led action may hold a static size. The hold must be on the **reaction**, not the action, and must stay under about 2 s — so it reads as a beat rather than as a breach of the budget. A wide held through a slugfest is the breach; a wide held on a deadpan face is the joke. For that beat only, the camera may sit. §3 still bans the words HOLD, static, and freeze — name the reaction.

## 2. Size menu

Mix; do not lock the whole clip to three-quarter **or** to left-right profile:

- extreme close-up (hand, blade, eyes)
- over-shoulder / running-in chase
- reverse over-shoulder
- side medium-wide
- worm's-eye
- high angle
- three-quarter finish

Open with a sting close-up or a chase when the story supports it.

## 3. Beat punctuation

If the user wants high-impact editing, **end the shot on a landed beat** (draw flare, hit, kick, slam, punch) and let the next shot open on the consequence. Do not freeze into a tableau after the boom.

Never write `HOLD`, `static shot`, `freeze`, or “stay on this wide.” The camera keeps moving inside every shot, except the reaction hold in §1 and a rack-focus shot from `references/coverage-menu.md`, whose head sits while focus travels. When `performance.md` is also on, that file may keep a face-beat shot still; coverage shots in this file still move.

## 4. Header

Append `· director` to the one-line header.

## 5. Self-check

Fix before showing if:

- a shot lasts ~5 s on one size without a long-take ask
- a cut opens on a posed idle
- `HOLD` / `static` / tableau language appears
- every shot is the same axis (all profile, or all 3/4)
